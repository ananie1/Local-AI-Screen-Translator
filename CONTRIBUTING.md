# Contributing to Local AI Screen Translator

First off, thank you for taking the time to contribute! Contributions from the community help make this tool better.

## How to Contribute

### 1. Reporting Bugs and Suggesting Features
If you encounter a bug or have an idea for an improvement (such as UI hotkey configuration or language selection menus), please open an issue on GitHub. 
* Provide clear steps to reproduce bugs.
* Describe feature requests clearly, explaining why they would be useful for other users as well.

### 2. Submitting Pull Requests
We welcome pull requests for bug fixes, performance improvements, and requested features.

1. Fork the repository.
2. Create a new feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'Add some amazing feature'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

### Code Style Guidelines
* Keep the code modular and clean.
* Maintain separation of concerns (keep UI logic separate from OCR and API client logic).
* Ensure your code works correctly offline without external dependencies other than those listed in `requirements.txt`.

# Внесение вклада в Local AI Screen Translator

Прежде всего, спасибо, что уделили время развитию проекта! Участие сообщества помогает сделать этот инструмент лучше.

## Как внести свой вклад

### 1. Сообщение об ошибках и предложение функций
Если вы столкнулись с багом или у вас есть идея по улучшению (например, настройка горячих клавиш через графический интерфейс или меню выбора языков), пожалуйста, откройте issue на GitHub.
* Опишите четкие шаги для воспроизведения ошибок.
* Подробно изложите суть предложения, объяснив, почему оно будет полезно другим пользователям.

### 2. Отправка Pull Requests
Мы приветствуем pull requests с исправлениями ошибок, улучшениями производительности и новыми функциями.

1. Сделайте форк (fork) репозитория.
2. Создайте новую ветку для вашей функции (`git checkout -b feature/amazing-feature`).
3. Закоммитьте изменения (`git commit -m 'Add some amazing feature'`).
4. Отправьте изменения в свою ветку (`git push origin feature/amazing-feature`).
5. Откройте Pull Request.

### Рекомендации по стилю кода
* Поддерживайте код чистым и модульным.
* Соблюдайте разделение ответственности (логика интерфейса должна быть отделена от OCR и клиента API).
* Убедитесь, что ваш код корректно работает оффлайн без внешних зависимостей, кроме тех, что указаны в `requirements.txt`.
